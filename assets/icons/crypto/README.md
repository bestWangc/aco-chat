# Crypto icon assets

The SVG files in this directory are imported from the open-source
[spothq/cryptocurrency-icons](https://github.com/spothq/cryptocurrency-icons)
collection (CC0-1.0). They are bundled locally so token and network icons do
not depend on runtime network access.

- `tokens/`: BTC, ETH, USDT, USDC, SOL, BNB, XRP, ADA, DOGE, TRX, LTC, AVAX,
  DOT, MATIC and ATOM.
- `chains/`: Bitcoin, Ethereum, Solana, BNB Chain, Tron, Avalanche, Polygon
  and Cosmos.
