# HarmonyOS Sans SC

These TTF assets are the complete Simplified Chinese HarmonyOS Sans SC font
files from Huawei's official HarmonyOS font archive.

<https://developer.huawei.com/consumer/cn/doc/design-guides-V1/font-0000001157868583-V1>

The application bundles the Thin, Light, Regular, Medium, Bold, and Black
weights. See `HarmonyOS-Sans-LICENSE.txt` for the bundled font license.
